# dotfiles
My dotfiles. Created & managed using `chezmoi`. 

## Installation
### macOS
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/nikloynes/dotfiles/main/bootstrap.sh)"
```

### Linux
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/nikloynes/dotfiles/main/bootstrap.sh)
```
